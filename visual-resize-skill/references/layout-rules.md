\f0\fs24 \cf0 # Layout Adaptation Rules\
\
## Horizontal to Vertical\
\
When adapting a horizontal design to a vertical format:\
\
1. Do not simply scale the original image.\
2. Preserve the main subject first.\
3. Extend the background upward or downward when possible.\
4. Rebuild the text area as a vertical hierarchy.\
5. Reduce decorative elements if they compete with the main message.\
6. Keep logo in a stable top-left, top-right, or bottom-safe position.\
\
## Vertical to Horizontal\
\
When adapting a vertical design to a horizontal format:\
\
1. Keep the main subject within the central or side visual zone.\
2. Expand background left and right.\
3. Place text on the side with more negative space.\
4. Avoid stretching the subject.\
5. Add visual balance through background continuation, not random new elements.\
\
## Square Adaptation\
\
When adapting to square:\
\
1. Focus on one central message.\
2. Reduce secondary content.\
3. Keep main title readable.\
4. Use tighter composition but preserve breathing space.\
5. Avoid placing important content too close to edges.\
\
## Text Hierarchy\
\
Text must be separated into:\
\
1. Main title\
2. Subtitle\
3. Supporting information\
4. CTA\
5. Legal or secondary note\
\
Do not flatten all text into the same size.\
\
## Protected Area\
\
Protected elements should not be cropped, distorted, regenerated, or overpainted:\
\
- Logo\
- Brand name\
- Main character\
- Product\
- Main title\
- QR code\
- Legal text\
- Facial features\
- Hands\
- Product label\
\
## Background Handling\
\
Background can be:\
\
1. Cropped\
2. Extended\
3. Blurred\
4. Simplified\
5. Reconstructed using the same color, lighting, material, and atmosphere\
\
Do not add unrelated objects.}
