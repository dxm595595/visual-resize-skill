\f0\fs24 \cf0 # QA Checklist\
\
## Text\
\
- All text matches the confirmed copy.\
- No missing characters.\
- No distorted strokes.\
- No incorrect punctuation.\
- No accidental translation.\
- No AI-generated fake text.\
- Text remains readable at final output size.\
\
## Layout\
\
- Main subject is not stretched.\
- Logo is clear and not distorted.\
- Key message remains inside safe area.\
- Visual hierarchy is clear.\
- Spacing is consistent.\
- Decorative elements do not block text.\
\
## Image Quality\
\
- No broken hands, faces, or product details.\
- No repeated artifacts.\
- No unwanted objects.\
- Background extension is consistent.\
- Lighting direction remains coherent.\
- Material style remains consistent.\
\
## Production\
\
- Correct size.\
- Correct aspect ratio.\
- Correct export format.\
- Correct resolution.\
- Bleed added for print.\
